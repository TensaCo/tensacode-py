# TensorCode 0.4.0 alpha implementation plan

Approved design: release 0.3.0, rename the message IR namespace to ops.text,
implement real pretrained transformer encoders and embedding-conditioned text and
diffusion image decoders. Public operations own parameters and preserve tracing,
training and complete checkpoint persistence.

Work stays on main; no branches/worktrees. Checkpoints use jacob-valdez. Heavy
foundation inference/training runs only on gb10-direct. Graph remains symbolic
stubs. Historical results retain their original paths/fingerprints.

## Contracts

Use existing Space and Latent: semantic identity, feature/sequence/spatial
organization, boolean masks and source metadata. Equal dimensions alone do not
imply compatibility. Decoders require declared input_space; optional context is
an ordered sequence of Latents in that same declared space (explicit separate
context_space if necessary), not arbitrary Python text hidden in a callback.
Pretrained operations accept complete JSON config, own nn.Module parameters,
trace normal calls, save native safetensors, and restore without network from a
local artifact. from_foundation explicitly acquires a pinned public foundation.
Random projections/readout tokens must be labeled as untrained, not pretrained
semantic bridges. Separate stochastic generation from differentiable target loss.

## Milestones and ownership

- [x] 0.3.0: version/package release; test/build; Git tag and GitHub release assets.
  PyPI credentials/trusted publisher are unavailable; do not claim PyPI upload.
- [x] Namespace worker: rename ops/llm to ops/text and tests/llm to tests/text;
  update live source, tests, examples, docs and CI. No old namespace alias.
  Preserve historical docs/results JSON. Test public imports and core no-torch
  import; preserve internal Decode weakref model ownership.
- [x] Text worker: owned transformer TextEncoder and embedding-conditioned
  TextDecoder, complete persistence and trace operation bindings. Encoder supports
  source-aligned sequences and foundation readout; new readout embeddings must
  be explicitly initialized/trained. Decoder projects latent/context to a masked
  input embedding sequence then runs the pretrained seq2seq transformer.
  Test masked input invariance, incompatible spaces, target-only loss, gradient
  flow into adapters, hooks, mixed modes, and fresh artifact/replay round trips.
- [x] Vision worker: owned vision transformer ImageEncoder with native processor,
  sequence/pooled outputs and correct patch provenance. Keep prior simple patch
  operation under explicit PatchEncoder; no fake pretrained default. Test actual
  tiny transformer parameters/gradients, preprocessing, context and persistence.
- [x] Diffusion worker: owned ImageDecoder/ImageDecode with conditioning adapter,
  denoiser, VAE and scheduler. Explicit noise/seed, scheduler/prediction type,
  latent scaling and image output conventions. Test native tiny diffusion
  denoising, context masks, deterministic noise, differentiable noise loss and
  complete offline checkpoint reload. Reject unsupported pipelines explicitly.
- [x] Parent integration: lightweight encoders get explicit VocabularyEncoder /
  PatchEncoder names; public TextEncoder/ImageEncoder select real transformers.
  Version 0.4.0a1; optional dependencies, exports, docs and diverse lifecycle
  examples. Existing tools keep their explicitly mechanical internal architecture.
- [x] Independent review and GB10 foundation checks: exact native baseline parity
  on compatible sequence inputs, source/context ablations, real output examples
  and fresh checkpoint reload. Do not claim arbitrary latent-space adapters work
  before training. Then full CPU suite, build, core import and CI; commit/push.

## Review focus

1. A loaded default operation must immediately work without reset workarounds.
2. Generation randomness must never be silently treated as deterministic replay.
3. Padding/context masks must actually affect transformer/diffusion conditioning.
4. Checkpoint/config provenance must survive tokenizer runtime mutation.
5. Loss targets must not enter source encoding or generation conditioning.

## Decisions

The user approved direct execution; no further design approval gate. Development
notes stay here so public docs remain developer guides. The release is GitHub
with distributions; PyPI publication remains unavailable without credentials.

- Source distribution and wheel build; installed wheel imports core/text/graph
  without PyTorch or Transformers. Diffusion extra resolves successfully.

  pass. Results and inherited-quality limitations are in

  bitwise diffusion output assertion. Follow-up verifies exact configuration and
  every restored weight, then uses the same 1e-6 tolerance as native parity for
  floating-point output. Eight focused tests pass; no source change required.

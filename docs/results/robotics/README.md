# Robotics results

[Watch the humanoid demo showcase](index.html).

Archived experimental evidence:

- [Compositional kitting](kitting/evidence.html): order revisions, quality rejection,
  physical grasp recovery and paired feedback baselines.
- [Humanoid walking and gripping](humanoid/index.html): G1 free-base simulation,
  substrate comparisons, physical gripping and open-gripper control.
- [Actuator calibration](calibration/index.html): fixed-base 20-joint tracking
  with a learned residual and disturbance comparison.

Each experiment is a sibling directory containing its report, media and evidence.
[Runnable source and reproduction guides](../../../examples/robotics/README.md)
use the same experiment names. Raw numeric records and archived execution source
retain their original bytes, hashes and historical paths.
